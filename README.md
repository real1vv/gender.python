# -Are-You-a-Woman-
이 코드는 남녀에 따른 성적욕구를 그림으로 표현한 예술입니다. 코드를 실행하게 되면 여자인지 아닌지를 물어보고 시작하는데, 그것에 대한 대답에 따라서 결과는 달라집니다. 만약 당신이 y(yes)로 대답하게 된다면, 여성이 보통적으로 추구하는 성적욕구를 표현시켜주는 그림이 나오고, 만약 n(no)로 대답하게 된다면 남성이 보통적으로 추구하는 성적욕구를 표현시켜주는 그림이 나옵니다. 이 예술작품에는 남녀가 서로 추구하는 성적 욕구가 다르듯이, 남녀의 성향차이는 '틀린 것'이 아니라 '다른 것'이라는 남녀평등적 의미가 담겨 있습니다.요즘같이 젠더갈등이 심화되고 있는 시대에, 이 작품이 널리 퍼짐으로써 도움이 되길 바랍니다.
